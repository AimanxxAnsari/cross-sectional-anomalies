# Cross-Sectional Anomalies

**Which published stock-return anomalies survive transaction costs, decay after publication and
multiple-testing corrections, out of sample?**

Academic finance has published hundreds of variables that appear to predict the cross-section of stock
returns. This project tests about 200 of them, drawn from roughly 150 published papers, under one common,
pre-registered set of tests, using only public data so that anyone can reproduce every number.

## Status

**Pre-registration in progress. There are no results yet.** The research plan, the hypotheses, the tests, the
settings and a sealed holdout period will be committed here before any results are produced, so the commit
history shows that the rules were fixed in advance.

## Data

Built on the [Open Source Asset Pricing](https://www.openassetpricing.com/) dataset (Chen and Zimmermann,
*Critical Finance Review*, 2022), with factor and risk-free rate data from Kenneth French's data library.
